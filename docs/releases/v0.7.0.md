# Nexo Device Care 0.7.0

[Português](#português) · [English](#english)

## Português

**Temperatura do processador no Windows, tudo atualizado para as versões mais recentes, animações refinadas, fonte nova e a tela de atualização arrumada.**

### Downloads
- **Windows:** `Nexo-Setup-0.7.0.exe` (ou o instalador visual `Nexo-Instalador-0.7.0.exe`).
- **Linux:** `Nexo-0.7.0-x86_64.AppImage` (qualquer distribuição) ou `Nexo-0.7.0-amd64.deb` (Debian, Ubuntu, Mint, Pop!_OS).

Quem já tem o Nexo instalado recebe esta versão pela atualização automática.

### Novidades
- **Temperatura do processador e da placa-mãe (Windows):** o Windows só libera essas leituras para um driver. Na primeira abertura, o Nexo pede permissão (UAC) e instala o **PawnIO**, o driver assinado e de código aberto que o LibreHardwareMonitor usa, junto com o serviço **“Nexo Device Care: sensores”**. O serviço só lê sensores. Se você recusar, dá para ativar depois em **Hardware**. Desinstalar o Nexo remove o serviço, e também o PawnIO se foi o Nexo que instalou.
- **Fonte Inter embutida:** textos mais nítidos e iguais no Windows e no Linux, sem depender das fontes do sistema.

### Melhorias
- **Animações refinadas:** uma curva de movimento só no app inteiro, uma única entrada por página (antes eram duas sobrepostas), cartões que terminam a animação sem cortar, menu, botões, chaves e janelas com resposta mais suave. O fundo agora acompanha o mouse com inércia, sem trancos.
- **Tudo na versão mais recente:** Electron 45.2.3, electron-updater 6.8.11, electron-builder 26.18.0 no instalador visual, .NET 10 com o serviço de sensores, Node 24 e as ações do GitHub atualizadas.
- **Hardware:** sem os filtros virtuais de rede repetidos (WFP, QoS, LightWeight Filter).

### Correções
- **Tela de atualização:** as notas da nova versão apareciam como código HTML. Agora aparecem como títulos e itens, só em português e sem a lista de downloads, e continuam visíveis depois que a atualização é baixada.
- **Letras quebradas:** as bandeiras-emoji viravam “BR” e “US” no Windows. Saíram das notas, do README e do histórico.
- **Temperatura “0 °C”:** um sensor sem acesso respondia 0 e o Nexo mostrava “0 °C · Dentro do esperado”. Agora isso não conta como leitura.
- **Segurança:** o alerta do Dependabot sobre o `minimatch` foi resolvido (versão 11.0.5 em todo o projeto).

## English

**Processor temperature on Windows, everything updated to the latest versions, refined animations, a new font and a fixed update screen.**

### Downloads
- **Windows:** `Nexo-Setup-0.7.0.exe` (or the visual installer `Nexo-Instalador-0.7.0.exe`).
- **Linux:** `Nexo-0.7.0-x86_64.AppImage` (any distribution) or `Nexo-0.7.0-amd64.deb` (Debian, Ubuntu, Mint, Pop!_OS).

If you already have Nexo installed, this version arrives through the automatic update.

### What's new
- **Processor and motherboard temperature (Windows):** Windows only allows these readings through a driver. On first launch, Nexo asks for permission (UAC) and installs **PawnIO**, the signed, open-source driver that LibreHardwareMonitor uses, together with the **“Nexo Device Care: sensores”** service. The service only reads sensors. If you decline, you can turn it on later in **Hardware**. Uninstalling Nexo removes the service, and PawnIO too if Nexo installed it.
- **Built-in Inter font:** sharper text that looks the same on Windows and Linux, without depending on system fonts.

### Improvements
- **Refined animations:** a single motion curve across the whole app, one entrance per page (there used to be two on top of each other), cards that finish their animation instead of being cut off, and smoother menu, buttons, switches and dialogs. The background now follows the mouse with inertia, without jerks.
- **Everything on the latest version:** Electron 45.2.3, electron-updater 6.8.11, electron-builder 26.18.0 in the visual installer, .NET 10 with the sensor service, Node 24 and updated GitHub actions.
- **Hardware:** no more repeated virtual network filters (WFP, QoS, LightWeight Filter).

### Fixes
- **Update screen:** the new version's notes showed up as HTML code. They now appear as headings and items, only in Portuguese and without the download list, and stay visible after the update is downloaded.
- **Broken letters:** flag emojis turned into “BR” and “US” on Windows. They were removed from the notes, README and history.
- **“0 °C” temperature:** a sensor without access answered 0 and Nexo showed “0 °C · Within the expected range”. That no longer counts as a reading.
- **Security:** the Dependabot alert about `minimatch` is resolved (version 11.0.5 across the project).
